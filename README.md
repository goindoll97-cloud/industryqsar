# IndustryQSAR — 반도체 공정 화학물질의 잠재적 흡입 혈액독성 스크리닝

**연구 2 | 연구 설계 v0.3 | 2026-11-27**

다양한 농도·기간의 흡입 노출에서 관찰된 혈액 및 조혈계 유해영향의 분자구조적 특성을 학습하여, 반도체 CMP 및 기타 제조공정에 도입되는 미지 산업용 유기화학물질의 정밀평가 우선순위를 제시하는 연구이다.

**현재 상태: 기존 공식기관 V10 및 인체 흡입 v0.2를 통합한 근거 데이터 v0.3 구축. 44 CAS, 원본 기록 114행(제외·자료부재 포함), 인용 검토 단위 92개, 후보 검토 단위 41개/20 CAS, 최종 학습 라벨 0개. 연구 원문 판정, 모델 학습 및 외부검증은 미완료.**

## 연구 질문

다양한 농도·기간의 흡입 혈액독성 자료로 학습한 구조 기반 모델이 장기간 저농도 직업성 흡입 노출과 관련된 혈액독성 물질을 선별할 수 있는가?

단기·고농도와 장기·저농도 독성 간 공통 구조적 신호 및 작용기전의 존재 가능성을 검증한다. 이를 모든 물질에 적용되는 확정적 사실로 가정하지 않는다. 동일 공정의 질병 사례는 연구 동기이며 개별 화학물질의 인과관계 증거가 아니다.

## 연구 범위: 인체 흡입 노출 전용

반도체 CMP 및 기타 제조공정의 작업환경에서 공기 중 화학물질의 직업성 노출을 중점적으로 평가하기 위해 흡입(inhalation) 경로만을 본 연구의 학습 및 독립검증 대상으로 설정한다. 급성·단기·반복·만성 및 고농도·저농도는 수집 단계에서 일률적으로 제한하지 않는다. 실제 인체 생체 내(in vivo) 흡입 및 직업성 공기 중 노출 근거만 검토한다. 동물실험과 세포실험 단독 자료는 학습 및 독립검증에서 제외한다. 경구·경피·주사 등 비흡입 자료와 노출경로 불명 자료는 기존 원자료에 보존하되 본 모델의 학습·검증 라벨 생성에 사용하지 않는다. 작업장 연구의 혼합 경로 또는 복합 물질 노출은 흡입 경로 및 개별 물질 귀속 근거를 별도 확인하며, 불명확하면 보류한다. 경피 등 다른 노출경로의 위험이 없다는 의미는 아니다.

## 핵심 설계

| 항목 | 연구 방향 |
|---|---|
| 예측 목적 | 잠재적 흡입 혈액·조혈계 유해성 스크리닝(hazard) |
| 학습자료 | 흡입 경로가 확인된 인체의 급성·반복·만성 근거; 농도 제한 없음 |
| 모델 입력 | 표준화 분자구조, fingerprint, 물리화학적 descriptor |
| 노출정보 | 농도·기간·경로·종 등은 보존하여 자료 선정, 층화 및 검증에 활용 |
| 핵심 독립검증 | 장기간 저농도 인체 직업성 흡입 근거 (가용성 확인 후 기준 고정) |
| 별도 검증 | 흡입 관련 림프조혈계 발암성(백혈병, 림프종, 다발골수종 등); 경로 불명은 보조 참조 |
| 해석 | 구조유사도, 유사물질 Top 5, 적용영역(AD), 구조적 기여도 |
| 적용 | CMP 우선 사례, 기타 반도체 및 산업용 유기화학물질 확대 |

혈액독성은 혈액암과 동일하지 않다. 결과는 안전 판정, 암 발생확률, 노출허용농도, 규제 지정 판정 또는 직업병 인과관계 판정에 사용하지 않는다.

## 기존 자료 활용

| 자료원 | 역할 |
|---|---|
| Long et al. | 보조 참조; 원자료 중 인체 생체 내 흡입 근거를 개별 확인한 경우만 학습 후보 |
| ToxRefDB v3 | 동물실험 자료는 학습 및 검증 제외; 기존 자료는 참고용 보존 |
| ATSDR | 인체 흡입 혈액독성 및 직업성 노출 근거 |
| EPA IRIS / OEHHA | 흡입 만성독성 및 발암성 근거 보완 |
| IARC | 흡입 관련 암종별 발암성 독립 참조; 다른 경로는 보조 자료 |
| A1 / A2 / CMP | 실제 적용 모집단; 이전 작업의 잠정 규모 249 / 7,833 / 56종 |

이전 ATSDR 작업에서 보고된 수집 규모: 보고서 184개, 후보 11,724행, 인체·흡입 우선 후보 949행, 통합 문맥 531개, 예비 판정 14건. 확정 라벨이나 독립 연구 수가 아니며, 원자료는 현재 저장소에 포함되어 있지 않다. 기존 전체 후보 재선별은 탐색용 감사 결과로 보존한다. 기존 949행과 전체 후보 중 흡입 표현 1,249행(중복 가능한 키워드 후보)을 포함해 인체 흡입 근거를 원 연구 단위로 재검토한다. 949행 및 1,249행은 확정 학습자료 수가 아니다. 다른 경로 및 경로 불명 자료는 본 분석에서 제외 또는 보류한다.

## 라벨 및 평가 원칙

- 흡입 경로가 확인된 신뢰성 있는 직접 혈액/조혈계 유해영향을 양성 후보로 사용. 중증 전신독성의 이차적 변화 등은 별도 검토.
- 특정 노출조건에서 영향 미관찰은 조건부 근거이며 물질 자체의 음성으로 자동 확정하지 않음.
- 자료 부재, 불확실, 상충 근거 및 적절히 뒷받침된 음성을 구분.
- 비발암성 혈액독성, 조혈계 독성, 림프조혈계 발암성 및 유전독성을 별도 관리.
- 동일 표준화 구조의 학습/검증 중복을 방지하고 원 연구 중복 인용을 추적.
- 흡입 단기(A), 흡입 반복노출(B), 흡입 통합(C) 학습 모델을 같은 독립 검증집합에서 비교. 표본수 및 구조 범위 차이를 통제하고 Recall, FNR, PR-AUC, AD coverage 등을 평가(음성 근거 부족 시 계산 가능한 지표만 보고).
- 유사도 단독 기준과 QSAR 비교; 유사도는 독성 확률이 아님.

## 실행 및 데이터 관리

신규 혈액독성 데이터 전처리·감사 코드는 hematotoxicity/에 있다. 새 모델의 학습 코드는 아직 구현되지 않았다. 기존 루트 Python 코드 및 테스트는 이전 급성경구 LD50 파일럿용이며 이번 연구의 혈액독성 예측에 사용하지 않는다. 기존 실행법은 보존 문서 참고(해당 문서의 docs/ 및 data/ 상대경로는 저장소 루트 기준).

원자료, 비공개 공정 정보, API 인증키는 공개 GitHub에 게시하지 않는다. 로컬 data/private/ 등을 사용하며 외부 자료의 재배포 조건을 확인한다. 실제 산업 적용은 독립검증과 안전보건 전문가의 검토 이후에 한정한다.
