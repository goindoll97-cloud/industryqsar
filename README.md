# IndustryQSAR — 반도체 공정 화학물질의 잠재적 혈액독성 스크리닝

**연구 2 | 연구 설계 v0.1 | 2026-11-27**

다양한 노출경로·농도·기간에서 관찰된 혈액 및 조혈계 유해영향의 분자구조적 특성을 학습하여, 반도체 CMP 및 기타 제조공정에 도입되는 미지 산업용 유기화학물질의 정밀평가 우선순위를 제시하는 연구이다.

**현재 상태: ATSDR 전체 후보의 자동 재선별 및 7물질 예비 문맥 검토 완료. 최종 라벨링, PDF 전체 암종 검색, 신규 모델 학습 및 외부검증은 미완료.**

## 연구 질문

다양한 노출조건의 혈액독성 자료로 학습한 구조 기반 모델이 장기간 저농도 직업성 흡입 노출과 관련된 혈액독성 물질을 선별할 수 있는가?

단기·고농도와 장기·저농도 독성 간 공통 구조적 신호 및 작용기전의 존재 가능성을 검증한다. 이를 모든 물질에 적용되는 확정적 사실로 가정하지 않는다. 동일 공정의 질병 사례는 연구 동기이며 개별 화학물질의 인과관계 증거가 아니다.

## 핵심 설계

| 항목 | 연구 방향 |
|---|---|
| 예측 목적 | 잠재적 혈액·조혈계 유해성 스크리닝(hazard) |
| 학습자료 | 적절한 급성·반복·만성, 인체·동물, 다양한 노출경로의 근거 |
| 모델 입력 | 표준화 분자구조, fingerprint, 물리화학적 descriptor |
| 노출정보 | 농도·기간·경로·종 등은 보존하여 자료 선정, 층화 및 검증에 활용 |
| 핵심 독립검증 | 장기간 저농도 인체 직업성 흡입 근거 (가용성 확인 후 기준 고정) |
| 별도 검증 | 림프조혈계 발암성(백혈병, 림프종, 다발골수종 등) |
| 해석 | 구조유사도, 유사물질 Top 5, 적용영역(AD), 구조적 기여도 |
| 적용 | CMP 우선 사례, 기타 반도체 및 산업용 유기화학물질 확대 |

혈액독성은 혈액암과 동일하지 않다. 결과는 안전 판정, 암 발생확률, 노출허용농도, 규제 지정 판정 또는 직업병 인과관계 판정에 사용하지 않는다.

## 기존 자료 활용

| 자료원 | 역할 |
|---|---|
| Long et al. | 범용 혈액독성 학습 후보; 보고된 원자료 2,382종의 라벨·고유 구조 재검증 |
| ToxRefDB v3 | 경구·흡입 등 혈액/조혈계 독성 및 노출 메타데이터 |
| ATSDR | 인체·동물 혈액독성 및 직업성 노출 근거 |
| EPA IRIS / OEHHA | 만성독성 및 발암성 근거 보완 |
| IARC | 암종별 발암성 독립 참조 |
| A1 / A2 / CMP | 실제 적용 모집단; 이전 작업의 잠정 규모 249 / 7,833 / 56종 |

이전 ATSDR 작업에서 보고된 수집 규모: 보고서 184개, 후보 11,724행, 인체·흡입 우선 후보 949행, 통합 문맥 531개, 예비 판정 14건. 확정 라벨이나 독립 연구 수가 아니며, 원자료는 현재 저장소에 포함되어 있지 않다. 기존 949행을 보존하면서 전체 후보를 노출조건 제한 없이 재검토하고 혈액암 관련 키워드를 추가한다.

## 라벨 및 평가 원칙

- 신뢰성 있는 직접 혈액/조혈계 유해영향을 양성 후보로 사용. 중증 전신독성의 이차적 변화 등은 별도 검토.
- 특정 노출조건에서 영향 미관찰은 조건부 근거이며 물질 자체의 음성으로 자동 확정하지 않음.
- 자료 부재, 불확실, 상충 근거 및 적절히 뒷받침된 음성을 구분.
- 비발암성 혈액독성, 조혈계 독성, 림프조혈계 발암성 및 유전독성을 별도 관리.
- 동일 표준화 구조의 학습/검증 중복을 방지하고 원 연구 중복 인용을 추적.
- 단기(A), 반복노출(B), 통합(C) 학습 모델을 같은 독립 검증집합에서 비교. 표본수 및 구조 범위 차이를 통제하고 Recall, FNR, PR-AUC, AD coverage 등을 평가(음성 근거 부족 시 계산 가능한 지표만 보고).
- 유사도 단독 기준과 QSAR 비교; 유사도는 독성 확률이 아님.

## 실행 및 데이터 관리

신규 혈액독성 데이터 전처리·감사 코드는 hematotoxicity/에 있다. 새 모델의 학습 코드는 아직 구현되지 않았다. 기존 루트 Python 코드 및 테스트는 이전 급성경구 LD50 파일럿용이며 이번 연구의 혈액독성 예측에 사용하지 않는다. 기존 실행법은 보존 문서 참고(해당 문서의 docs/ 및 data/ 상대경로는 저장소 루트 기준).

원자료, 비공개 공정 정보, API 인증키는 공개 GitHub에 게시하지 않는다. 로컬 data/private/ 등을 사용하며 외부 자료의 재배포 조건을 확인한다. 실제 산업 적용은 독립검증과 안전보건 전문가의 검토 이후에 한정한다.
