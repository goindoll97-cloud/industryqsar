# v0.27-supplement-draft — 보충자료 제출 전 정제 및 검증

상태: NITE 공식 유해성/구조 감사의 기술적 스냅샷 고정, 인체·동물 흡입 및 독성 유형별 최종 판정 미고정. 최종 투고본 아님. v0.26 A/B 역할, 예비실험, 결과는 그대로 보존.

## 실제 수행
- v0.26 ZIP manifest 18개 해시 일치; v0.27 출력 22개 해시 검증 통과.
- NITE 562 CAS, 747 분류행을 기존 원본과 근거문/해시 대조. 구조 통과 332종, 보류 230종. 332종과 B 후보 2,519종의 전체 InChIKey를 RDKit 2025.09.4로 재계산, A와 후보 B 간 CAS/연결성 중복 없음. B 후보 내부 연결성 2,492개.
- 구조 확보 NITE 근거 417행: 기존 요약문 검토 82 + 신규 12 = 94, 추가 발췌문 선별 28, 자동 단서만 295. 전체 요약문 검토 대기 323행. 독립 원저 수와 동일하지 않음.
- NITE 동물 흡입 보완 근거: 36종에서 39종으로 잠정 증가(Allyl chloride, Diuron, Fenothiocarb). 1,1-Dichloroethylene은 NTP TR582 원보고서 관련 절 검토 후 체중 관련 변화 가능성으로 보류. 원저 전수 검증 아님.
- 인체 기존 16종 재점검, 문헌 연결 27행 기록. 2-Methoxyethanol 및 2-Ethoxyethyl acetate 원저 관련 절 확인: 경피 기여 배제 불가, 직업성 확장 유지. 전체 독립 원저 판정 미완료. 신규 최종 라벨 0.
- A 349, B 8,110, 스크리닝 후보 2,519 유지. TRI 전용 28 CAS를 로컬 원목록과 대조하고 [EPA TRI 기관 URL](https://www.epa.gov/toxics-release-inventory-tri-program/tri-listed-chemicals) 보완. 원래 TRI 목록 버전 및 개별 등재 독립 검증 미완료. 반도체 핵심 범위 249 중 4개 사용조사 행 정확 출처 대기. 신규 EPA 328 CAS의 원본 다운로드 파일은 없음(투영 및 기록 해시만 보존).

## 재현 및 남은 작업
로컬 ZIP의 `build_v27.py --base PATH_TO_INPUTS --out NEW_DIRECTORY`를 실행하고 `validate_v27.py --tables NEW_DIRECTORY`로 해시/행 수 검증. 필요한 원본 목록은 로컬 S01 입력 manifest 참조. 독성 근거 검증은 자동 검사와 구분한다.
