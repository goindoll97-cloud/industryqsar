# Data dictionary (v0.3)

CSV: UTF-8, LF, comma-separated, all fields quoted. Blank is unknown/not assigned, never zero or negative.

## Integrated evidence
`evidence_id`: original stable source ID; `source_version`: official_v10 or human_inhalation_v02; `cas_rn`, `chemical_name`: source identity; `citation`: source study reference (may be grouped); `agency`: source agency or primary_article; `source_url`, `source_locator`: original evidence location (V10 section/page, v0.2 PDF page and row IDs); `reported_route_species`: source route/species statement, may be blank or uncertain; `endpoint_class`: hematology or cancer; `endpoint`: assessed/reported outcome; `original_status`: unmodified source assessment; `exposure_context`: V10 free text (may include non-measurement reference values); `concentration`, `duration`: v0.2 original free text, not standardized; `observed_result`: V10 outcome if recorded; `limitations`: source caveats plus documented scope exclusion; `source_access_date`: source-reported date, blank if unknown; `review_bucket`: candidate (potentially relevant human inhalation evidence, not confirmed), hold (attribution, adversity or source discrepancy pending), excluded (out of scope), data_gap (no evidence/search-only), cancer_separate (separate endpoint); `training_label`: blank; `citation_review_group`: linked citation review ID, not independent study ID.

## Citation/cohort links and groups
`evidence_id_a`, `evidence_id_b`: linked source records; `relationship`: same cited study, same grouped citations, partial citation overlap, probable citation overlap, related distinct exposure arm, same cohort reanalysis, or possible cohort overlap; `grouped`: 1 if grouped for review, 0 if link only; `review_status`: pending primary verification. `citation_review_groups.csv` contains `citation_review_group`, `cas_rn`, `evidence_ids` (semicolon list), `source_rows` (row count), `review_bucket` (hold if any member hold or buckets disagree), `original_statuses` (distinct source values), `training_label` (blank). Links are manually proposed and not an exhaustive deduplication.

## Chemical inventory
`cas_rn`, `chemical_name`: candidate identity; `smiles_input`: original or manually proposed structure; `rdkit_canonical_smiles`: RDKit canonicalization, not registry verification; `smiles_origin`: v02, v10, manual_proposal, none; `identity_status`: candidate_not_registry_verified or mixture_or_unresolved; `structure_scope`: organic_candidate, excluded_mixture, excluded_inorganic_carbon; `v10_group`, `v10_A1_tier`: source industrial inventory assignment, blank if unavailable; `v10_rows`, `v02_rows`: source row counts; `citation_review_groups`, `candidate_groups`, `hold_groups`, `excluded_groups`, `gap_groups`, `cancer_groups`: descriptive group counts; `training_label`: blank. `training_labels_pending.csv`: CAS, verified canonical SMILES, final adjudicated label, evidence IDs, reviewer and date (no data rows).

## Original V10 tables
The V10 tables preserve original fields. `CASRN`, `name` identify substances; `evidence_id`, `agency`, `assessment_year`, `report`, `url`, `locator`, `cited_study`, `endpoint`, `route_species`, `status`, `exposure_context`, `limitations`, `access_date`, `primary_fulltext_review`, `reviewer_signoff`, `book_id`, `group`, `observed_result`, `final_label` are source metadata. `assessment_year` is assessment date, not primary publication year. `book_id` is NCBI Bookshelf locator. `group` and `A1_tier` are prior inventory categories. Chemical review `evidence_count`, `statuses`, `evidence_ids` are prior summaries; `canonical_smiles` is the prior candidate structure. No source status is overwritten by v0.3.
