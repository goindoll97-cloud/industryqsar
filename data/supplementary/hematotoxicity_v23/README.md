# v0.23 — 인체·동물 흡입 혈액독성 통합 (로컬 작업본)

A 39 CAS(인체 기존 36, 신규 동물 전용 3). 기존 인체 근거와 역할은 유지하고 동물 근거 및 모델 적용 역할을 독립 컬럼으로 기록. 잠정 동물 근거 7종 중 기존 EPA/RDKit 구조 대조 충족 4종, 신원 보류 3종; 민감도 전용 2종. 18종 개별 판정은 ATSDR 19문맥, PubMed 1초록을 근거로 하며 원저 전수 검증이 아니다. 기존 후보 2,869문맥/1,795초록 대부분 개별 검토 대기. B 8,110종 유지, 1,3-butadiene 1종을 참조 중복으로 분리하여 신규 후보 2,642종. 동물 양성을 인체 양성으로 간주하지 않는다. 최종 라벨/모델 없음.

같은 방법의 인체 단독/동물 단독/통합 참조 비교를 계획한다. 검증 인체 물질의 동일 CAS/구조 및 구조군을 참조 풀에서 제외하고 해당 동물자료도 제외한다. 기존 인체 판정 역시 잠정 상태. 전체 CSV, 근거표, 재현 코드는 로컬 hematotoxicity_v23.zip에 보존. 공개 CSV 버전 v0.18 유지. [manifest](summary.json).
