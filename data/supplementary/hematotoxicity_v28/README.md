# v0.28 — 공식 유해성 분류 근거 재도출 및 노출경로·독성유형 분류

상태: 최종 투고본 아님. NITE 공식 혈액계 분류 계층은 재현 및 고정, 노출경로·근거종·독성유형별 연구 데이터셋은 미고정. **신규 확정 양성 라벨 0건. 독립 원저 전문 검증 완료 0건.**

## 1. v0.28에서 달라진 점

v0.27에서는 구조 확보 근거 417행 중 323행의 공식 분류 근거 요약문 검토가 남아 있었다. 분류 근거 원문이 물질별 상세 페이지로만 확보 가능했기 때문이다.

v0.28에서 NITE가 분류 근거 전문을 **일괄 파일로 공개**하고 있음을 확인하였다. 공식 다운로드 페이지에는 v0.24~v0.27 입력 목록에 없던 두 번째 워크북 **`list_rational_e.xlsx`** 가 있으며, 전체 물질 × 유해성 항목의 *"Rationale for the classification"* 원문 117,026행(STOT 6,904행)을 담고 있다.

따라서 v0.28은 323행 부분 검토를 수행하지 않고, **혈액계 분류 749행 전체**의 근거 원문을 재도출하여 **3,634개 개별 근거 단위**로 분할하고 각 단위의 원문을 함께 보존하였다.

## 2. 기존 공개 분류집합의 재현

2026-11-28자 공식 다운로드 기준 재도출 결과는 기존 v0.24~v0.27 스냅샷을 재현한다.

| 항목 | v0.24~v0.27 기록 | v0.28 재도출 | 일치 |
|---|---:|---:|---|
| 혈액계 STOT 근거행 | 747 | 747 | 완전일치 |
| 단일 CAS | 562 | 562 전부 회수, 누락 0 | 완전일치 |
| 골수·조혈계 표적 | 60 | 60 | 완전일치 |
| SE만 / RE만 / 양쪽 | 73 / 310 / 179 | 74 / 307 / 179 | ±3 |
| Cat 1 포함 / Cat 2만 | 377 / 185 | 376 / 184 | ±1 |

기존 562종을 정확히 재현하는 선정규칙: STOT-SE 또는 STOT-RE **Category 1 또는 2** 에서 `blood`, `blood system`, `bone marrow`, `hematopoietic system`, `hematopoietic organ` **또는** `blood coagulation system` 이 표적장기로 지정된 항목, CAS 셀은 분할하지 않고 집계.

### 기존 집합에 영향을 주는 확인 사항 3건

1. **562종 중 5종은 혈액응고계 단독 분류이다.** Estrone, 2,4-Di-tert-butylphenol, Chlormadinone acetate, 4-sec-Butyl-2,6-di-tert-butylphenol, Indanofan은 혈액 관련 표적장기가 `blood coagulation system` *뿐*이다. 응고·지혈 독성은 본 연구의 Type 1~3 틀 밖이며, 특히 두 스테로이드 호르몬은 혈전 경향 증가로 혈액독성과 기전상 반대 방향이다. 규칙 R02로 분리하였다(gap `G12`).

2. **v0.24 파이프라인에서 2종이 누락되었다.** NITE가 하나의 셀에 CAS 두 개를 기재하기 때문이다: **Thiouracil**(141-90-2 / 80275-68-9), 6-Acetyl-1,1,2,4,4,7-hexamethyltetralin(21145-77-7 / 1506-02-1). Thiouracil은 혈액계 **STOT-RE Category 1** 항목이고 thiouracil계는 무과립백혈구증의 확립된 원인물질이므로 누락의 의미가 크다(gap `G11`).

3. **NITE 자료 자체의 변동.** 현재 다운로드는 STOT 항목 보유 물질 3,452종으로, v0.24 기록 3,476종과 다르다. 근거행이 없는 24종은 모두 SE/RE가 `-` 이므로 혈액계 선정에 영향이 없다.

## 3. 방법: 전체 셀 키워드가 아닌 근거 단위 단위 판정

NITE 분류 근거는 하나의 셀 안에서 인체 직업성 자료, 동물 흡입 자료, 동물 경구 자료를 연속된 문장으로 함께 기술한다. 따라서 전체 셀 키워드 방식으로는 프로토콜이 요구하는 두 질문에 답할 수 없다. **어느 종에서 나온 관찰인지**, 그리고 **흡입시험에서 실제로 확인된 것인지**.

v0.28의 모든 판정은 단일 근거 단위 수준에서 수행한다. FY2018~FY2023 항목은 번호가 붙은 `[Evidence Data]` 항목(172건), 비정형 서술형은 문장 단위(573건)로 분할하고, 판정 근거가 된 원문을 함께 보존한다.

노출경로 어휘는 단순 판독이 혼동하는 세 경우를 구분한다.

| 값 | 의미 |
|---|---|
| `inhalation` | **같은 단위** 안에 명시적 흡입 표현과 독성지표가 함께 존재 |
| `route_not_specified_air_unit_only` | 노출량이 ppm·mg/m³ 로만 제시되고 흡입 표현 없음 |
| `oral_dietary_concentration_inferred` | ppm이 사료·식이 표현과 함께 등장 |

세 번째가 중요하다. **NITE는 사료 투여시험의 식이 농도를 ppm으로 표기한다.** 이를 처리하기 전에는 식이 ppm 투여시험이 흡입시험으로 오판정되었다. 수정 결과 근거 단위 218개가 경구로 이동하고 허위 흡입 신호 155개가 제거되었다.

본 방법은 의도적으로 **보수적**이며 과대판정보다 과소판정 쪽으로 기울어 있다. 벤젠이 그 예로, 인체 직업성 조혈계 근거가 ppm 수치는 있으나 "inhalation" 표현이 없어 tier A가 아닌 tier B로 분류된다(gap `G09`).

### Type 3에서 보상성 반응 분리(규칙 R08)

프로토콜 요구사항대로 골수의 직접 손상과 적혈구 파괴 이후의 보상성 조혈 반응을 구분하였다.

| 판정 | 물질 수 |
|---|---:|
| `type3_marrow_injury_supported` — 보상성 표현이 없는 단위에서 골수 표현 확인 | 149 |
| `type3_peripheral_counts_only` — 말초 혈구수 변화만, 골수 표현 없음 | 96 |
| `type3_marrow_signal_compensatory_only` — **골수 손상 판정 보류** | 23 |

Diuron이 대표 사례다. NITE 근거에 sulfhemoglobin 생성, RBC·Hb 감소, 망상적혈구 증가, Heinz body, 비장 골수외 조혈, "reactive" 골수 조혈이 기술되어 있다. 이는 산화적 용혈성 빈혈과 보상 반응이며 일차적 골수독성이 아니다.

### STEP 5에 결정적인 방법론적 확인

혈액계 분류 근거의 인용 3,007건 중 원저 시험보고서(NTP technical report 또는 OECD TG 시험)를 직접 지목하는 것은 **249건**뿐이다. 나머지는 권위 있는 2차 종합자료(ACGIH, DFG MAK/DFGOT, PATTY, IPCS CICAD/EHC, EU-RAR, ATSDR, IARC) 또는 일본 국가평가자료를 인용한다.

**tier A 인체 흡입 11종 중 원저 학술논문을 인용한 물질은 하나도 없다.**

따라서 NITE 혈액계 분류는 **공식 유해성 분류와 그 근거**를 확립하지만, 인체 흡입 혈액독성의 **원저 검증을 대체하지 않는다.** 이것이 *공식 혈액독성 유해성 참조* 와 *인체 흡입 핵심 참조* 를 별도 역할로 유지해야 하는 근거다(gap `G05`).

## 5. 기존 인체 참조집합 감사

공개 v0.18 Dataset A 인체 참조 28건 전부를 공식 분류와 대조하였다(`S08_published_human_reference_audit.csv`).

**독립적으로 교차 확인된 물질** — Naphthalene, Methanethiol은 tier A 도달. Benzene, 2-Bromopropane은 tier B 도달이며, 후자는 보고된 범혈구감소증과 골수 저형성을 교차 확인한다.

**단일 출처 지지, 논문에 명시 필요** — 4건은 공식 NITE 혈액계 분류가 **전혀 없다.** 그중 3건이 최상위 `1_core` 수준이다: 4-Bromo-2-fluoroaniline, 5-Amino-2-(trifluoromethyl)pyridine, Dichloromethane, 그리고 2-Ethoxyethyl acetate(`2_extended`). 이들은 v0.18에 기록된 원저 증례보고에만 의존한다.

## 6. tier A 5종의 원저 대조 수동 검토

tier A 5종에 대해 PubMed에서 원저를 탐색하고 실제로 읽어 판정하였다(`S08b`). **5건 중 3건에서 원저 문헌이 NITE 요약의 주장을 제한한다.** 이것이 이 작업의 목적이다.

| 물질 | 판정 |
|---|---|
| **2-Ethoxyethanol** (110-80-5) | 인체 직업성 혈액학적 근거는 실재하나, 중재연구가 **고무장갑 착용 추가**로 개선을 달성하여 경피 기여가 상당함을 시사. 골수손상 보고는 glycol ether와 *다른 용제* 혼합노출 인쇄공 대상. → 직업성 확장, 흡입 핵심 아님 |
| **1,2-Dichloropropane** (78-87-5) | 인체 보고가 **혼합 소비자제품**(얼룩제거제, 고무풀) 노출이며 가장 명확한 급성 사례는 경구 섭취. 명확한 흡입자료는 동물. NITE의 "만성 흡입이 용혈성 빈혈 유발"은 단일물질 인체 흡입 소견으로 재현되지 않음. → 기존 `3_uncertain / sensitivity_only` 유지 |
| **Lindane** (58-89-9) | 인체 골수독성은 충분히 문헌화되고 인체 전구세포 in vitro 시험으로 지지되나, 원저 증례의 노출경로는 **경피**(국소 구충제) 또는 전신중독이 주류이며 직업성 흡입이 아님 |
| **o-Toluidine** (95-53-4) | 인체 Type 1 기전은 강하게 지지되나 주로 **prilocaine** 대사를 통한 것(o-toluidine이 약물 대사체), 즉 전신 약물노출. 직업성 20/81 관찰은 1992년 DFG MAK 자료 출처이며 미입수 |
| **Nitrogen monoxide** (10102-43-9) | 경로·지표는 잘 지지되나 접근 가능한 원저는 신생아·ARDS 환자의 **치료적** 흡입 NO가 압도적이며 직업성 노출이 아님 |

공식 근거에서 새로 드러났으나 기존 인체 16종에 **없던** 인체 흡입 후보로 2-Ethoxyethanol, Nitrogen monoxide, o-Toluidine, m-Aminophenol, p-Nitrochlorobenzene, Lindane 등이 있다. 산업적으로 유의한 물질이 포함되며, Nitrogen monoxide와 Nitrous oxide는 반도체 공정가스다. 어느 것도 확정 라벨로 승격하지 않았다.

## 7. 이 작업에서 수행할 수 없었던 것

`S11_gap_register.csv`(12건)에 전부 기록하였다. 주요 제약:

- **`hematotoxicity_v27_supplement.zip` 미확보.** 따라서 Dataset A(349), Dataset B(8,110), 스크리닝 후보(2,519)는 **재생성 또는 직접 갱신이 불가**하였다. v0.28은 대체 Dataset A가 아니라 CAS 기준 결합 계층(`S10`)을 제공하여, 로컬 표의 내용을 추측하지 않고 병합할 수 있게 하였다.
- **94검토 / 323대기 행 매핑을 복원할 수 없음.** 해당 정보가 같은 ZIP 안에 있다. 대신 749행 전체를 읽었으므로 부분검토는 대체되었으나, 기존 플래그와의 행 단위 매핑은 미해결로 남는다.
- **어떤 물질에 대해서도 원저 전문 검증을 완료하지 않았다.**
- **PubChem 구조감사는 고정된 EPA 기반 S03을 대체하지 않는다.** 다른 등록 체계를 조회하므로 수치가 다르며(여기 570 CAS 중 단일성분 유기 390, v0.27은 562 중 332) 혼용해서는 안 된다.
- **STEP 6 미해결**: TRI 전용 28종의 목록 버전과 개별 등재 근거, 반도체 핵심 249종 중 4건의 정확한 출처, EPA CompTox CCD-Batch-Search 원본 export.

## 10. 유지한 제약

- 신규 모델 개발·실행 없음. 실험 수행 없음.
- 신규 독성 데이터베이스 추가 없음. `list_rational_e.xlsx`는 프로토콜에 이미 있는 NITE 출처의 두 번째 파일이며 새로운 출처가 아니다.
- 동물과 인체 혈액독성을 하나의 양성 라벨로 병합하지 않음.
- 독성자료 부재를 음성 라벨로 기록하지 않음.
- 어떤 물질도 확정 양성 혈액독성물질로 표시하지 않음.
- 표적장기 분류, 실제 관찰 독성지표, 독성 작용기전을 별도 필드로 유지하고 동일 개념으로 취급하지 않음.
- v0.26 예비실험 결과와 v0.18 공개 A/B CSV는 변경하지 않음.
