# v0.20 — EPA 우선 조회 실제 병합 (로컬 데이터, 공개 manifest)

사용자가 제공한 CompTox CSV 2,020행은 v0.19 우선 조회 CAS 집합과 정확히 일치했다. 2,019개 입력·반환 CAS 일치, 1개 대체 CAS 보류. 원본 SMILES를 RDKit으로 계산해 전체 InChIKey가 일치하고 유기 단일성분 범위에 해당한 779종을 잠정 승인했다(신규 검토 762, 기존 참조 중복 17). 미조회 이전 구조 52종은 별도 상태로 유지해 전체 잠정 구조 831종이 되었다. 이전 미해결에서 610종 신규 확인, 이전 적격 16종 보류.

762종의 구성: 반도체 109, 전자산업 131, 공정기능 522. 기존 문헌 검색 단서 46종, 그 외 716종은 독성자료 부재나 음성을 의미하지 않는다. A는 29종(주 분석 잠정 16, 불확실 13) 그대로 보존했다.

원본 549개 필드 중 식별정보 9개만 병합에 사용했으며 나머지 목록 플래그는 독성 라벨로 사용하지 않았다. 전체 키가 불일치하거나 대체 CAS, 원래 신원 충돌은 보류했다. 653종은 반환 구조 표현상 적용범위 밖이며 최종 물질 신원/위험 판정이 아니다. 6,090종 미조회 CAS는 로컬 조회 목록에 저장했다. 공정 사용/개인 노출 및 독성 근거 검증은 여전히 미완료. 모델 실행/최종 라벨/순위 없음.

전체 파일 및 재현 코드는 로컬 hematotoxicity_v20.zip에 보존. GitHub에는 실제 결과 집계와 파일 SHA256만 등록; 전체 데이터 공개 버전은 v0.18 그대로 유지.
