# v0.21 — EPA 전체 모집단 조회 병합 (로컬 데이터, 공개 manifest)

두 EPA CSV(2,020 및 6,092 반환행)를 v0.19 원본으로부터 동일한 v0.20 기준으로 재병합. 전체 8,110 CAS 조회 완료, 8,112 반환행. 다중 매칭 2종 보류, 이전 2,020종의 판정 유지. 잠정 구조 기준 통과 2,674종(신규 2,650, 참조 중복 24). 구조 미확보 2,058종, 신원 검토 766종, 적용범위 외 또는 기존 범위 보류 2,612종. 기존 범위 제외의 독립 재판정은 미수행. 신규 후보 중 반도체 109, 전자산업 131, 공정기능 522, 기타 산업 1,871, TRI 단독 17. 기존 문헌 단서 66종을 우선 검토 목록으로 추출; 음성 판정 아님. A 29종(잠정 주 분석 16) 변경 없음. 독성 라벨 및 모델 점수 없음.
