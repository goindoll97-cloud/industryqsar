## v0.28 정정 사항 (이전 기록을 소급 변경하지 않음)
1. 323행 read_in_v028은 원문 자동 분할·추출 및 매칭 완료이며 개별 독성학적 수동 판정 완료가 아니다. G03은 자동 처리 완료, 원저 및 분석 참조 개별 검토는 열려 있음. G13의 추가 검토 불필요 결론은 자동 판독만으로 정당화되지 않는다.
2. Type3 149건은 골수 관련 문구 및 보상성 단서 부재 후보, 직접 손상 확정이 아니다. v0.28 summary 23 보상성 단독 vs gap 27, 실제 공개 색인 집계 23을 기준으로 한다.
3. 신규 다중 CAS는 고유 번호 4개에 연결행 8개. 566 NITE substance entry, 570 CAS 연결행은 고유 CAS 수와 다르다. 각 CAS와 실제 개별 신원을 검토.
4. 전체 key conflict 24행: 공개 구조표 기준 단일 유기 4, 무탄소/무기 17, 다성분 3. 유기 연결성 일치 42행은 기존 보류 38, 기존 통과 2, CAS 불일치 2. 42종 일괄 해제 금지. 40 보류의 실제 재계산은 위 결과 참조.
5. PubChem 첫 결과 자동 선택 금지, 다중 hit와 CAS 동의어/등록번호 및 구조 신원 확인 필요.
6. 응고계 단독 5종은 공식 스냅샷 보존, Type1~3 분석 범위 밖으로 분리하는 안 제안. 응고 이상이 혈액독성이 아니라는 일반적 주장은 하지 않는다.
7. v0.28 코드 절대경로 및 full workbook 재실행/통합은 미완료. v0.29 독립 audit_v29.py는 명령행 입력 경로로 실행 가능.
