# 혈액독성 스크리닝 연구 인수인계 — v0.28 기준

작성: 2026-11-28 · 최신 데이터 작업본 `v0.28-evidence-rederivation` · 최신 실험 `v0.26-pilot2` · 공개 A/B CSV `v0.18`

## 0. 현재 상태 한 줄 요약

NITE 공식 혈액계 분류 계층은 현행 공식 출처 기준으로 재현·고정되었고, 749행 전체의 분류 근거 원문을 읽어 근거종·노출경로·독성유형 분류를 완료했다. v0.27 로컬 아카이브를 해시 검증 후 병합하고 **미검토 323행을 전수 판독**했다. **확정 양성 라벨 0건, 독립 원저 전문 검증 0건.**

### 가장 중요한 결론: 323행에는 새로운 경로별 근거가 사실상 없다

전수 판독 결과 **신규 동물 흡입 2행, 신규 인체 흡입 0행**이다. `no_inhalation_text_cue` 로 분류된 112행 중 흡입 소견으로 전환된 것은 하나도 없다. v0.25~v0.27 우선순위 검토가 경로별 근거를 이미 포착했으므로, **이 자료에 대한 추가 전수 검토에 시간을 쓸 필요가 없다.** 남은 병목은 근거 수집이 아니라 2차 종합자료 입수와 원저 전문 검증이다.

## 1. v0.28에서 실제로 수행한 것

- NITE 공식 다운로드 페이지에서 **`list_rational_e.xlsx`** 발견·확보. 전체 물질 × 유해성 항목의 분류 근거 원문 117,026행. v0.24~v0.27 입력 목록에 없던 파일이다. 이것이 v0.28의 핵심 전환점이다.
- 혈액계 STOT Cat 1/2 분류 **749행 전체**를 재도출하고 근거 원문을 **3,634개 근거 단위**로 분할. v0.27에 남아 있던 "323행 요약문 검토"는 부분 검토가 아니라 전수 검토로 대체되었다.
- 기존 공개 562종 집합을 **정확히 재현**(747행, 562 CAS 전부 회수, 골수·조혈계 60종 완전일치). 재현 선정규칙과 모든 차이의 원인을 규명해 `S02b` 에 기록.
- 근거종·노출경로·독성유형을 **근거 단위 단위로** 판정. 전체 셀 키워드 방식의 한계를 구조적으로 제거.
- 인용 출처 등록부 3,007건 생성 및 증거 계층(원저 시험보고서 / 권위 2차 종합자료 / 국가평가 / 2차 DB) 분류.
- PubChem + RDKit 2025.09.4 독립 구조감사(570 CAS), 응답 전문 캐시 보존.
- 공개 v0.18 인체 참조 28건 전부를 공식 분류와 대조 감사.
- tier A 5종에 대해 PubMed 원저 탐색 후 **직접 열독하여 수동 판정**.
- 검증 31건 수립·통과, 미확보 입력 2건은 `SKIP` 보고. 미해결 공백 12건 등록부 작성.

## 2. 반드시 알아야 할 확인 사항 5건

### (1) 562종 중 5종은 혈액응고계 단독 분류
Estrone, 2,4-Di-tert-butylphenol, Chlormadinone acetate, 4-sec-Butyl-2,6-di-tert-butylphenol, Indanofan. 혈액 관련 표적장기가 `blood coagulation system` 뿐이다. 응고·지혈 독성은 Type 1~3 틀 밖이고, 두 스테로이드 호르몬은 혈전 경향 증가로 혈액독성과 기전상 반대다. 규칙 R02로 분리했다. **결정 필요: 응고계를 제4유형으로 둘지, 공식 참조집합에서 제외할지.**

### (2) v0.24에서 2종이 누락되었다
NITE가 하나의 CAS 셀에 번호 두 개를 기재하기 때문이다.
- **Thiouracil** (141-90-2 / 80275-68-9) — 혈액계 **STOT-RE Category 1**
- 6-Acetyl-1,1,2,4,4,7-hexamethyltetralin (21145-77-7 / 1506-02-1) — STOT-RE Cat 2

thiouracil계는 무과립백혈구증·무형성빈혈의 확립된 원인물질이므로 누락의 의미가 크다. **결정 필요: 두 물질 편입 여부.** CAS가 없는 Chlorotrifluoroethane 1종도 같은 이유로 빠져 있다.

### (3) NITE 분류는 원저 검증을 대체하지 않는다 — STEP 5의 전제
혈액계 근거 인용 3,007건 중 원저 시험보고서(NTP TR, OECD TG 시험) 직접 인용은 **249건뿐**이다. 나머지는 ACGIH, DFG MAK/DFGOT, PATTY, IPCS CICAD/EHC, EU-RAR, ATSDR, IARC 등 2차 종합자료 또는 일본 국가평가자료다. **tier A 인체 흡입 11종 중 원저 학술논문을 인용한 물질은 하나도 없다.**

이것이 *공식 혈액독성 유해성 참조* 와 *인체 흡입 핵심 참조* 를 별도 역할로 유지해야 하는 증거적 근거다. 논문 방법론 서술에 그대로 쓸 수 있다.

### (4) 공개 v0.18 인체 참조 4건은 공식 분류 지지가 없다
그중 3건이 최상위 `1_core` 다.
- 4-Bromo-2-fluoroaniline (367-24-8) — `1_core`
- 5-Amino-2-(trifluoromethyl)pyridine (106877-33-2) — `1_core`
- Dichloromethane (75-09-2) — `1_core`
- 2-Ethoxyethyl acetate (111-15-9) — `2_extended`

v0.18에 기록된 원저 증례보고에만 의존한다. 제외 사유는 아니지만 **단일 출처 지지임을 논문에 명시해야 한다.** 반대로 Naphthalene·Methanethiol은 tier A, Benzene·2-Bromopropane은 tier B로 독립 교차 확인되었다.

### (5) ppm은 사료 농도일 수 있다
NITE는 흡입시험의 공기 중 농도와 사료 투여시험의 식이 농도를 모두 ppm으로 표기한다. 처리 전에는 식이 ppm 투여시험이 흡입시험으로 오판정되었다. 수정 결과 근거 단위 218개가 경구로 이동하고 허위 흡입 신호 155개가 제거되었다. **향후 어떤 경로 분류 작업에서도 이 함정을 유지 관리해야 한다.**

## 6. 다음 작업 순서 권고

1. **결정 2건 확정.** 응고계 단독 5종 처리(제4유형 vs 제외), 다중 CAS 누락 2종 특히 **Thiouracil**(혈액계 STOT-RE Cat 1, 무과립백혈구증 확립 원인물질) 편입 여부.
2. **구조 보류 40건 해제 검토(`G14`).** EPA export의 InChI 표준화 플래그를 확인해 비표준 키 인공산물임을 확정하면 구조 확보 참조가 실질 증가한다. 단일 InChI 표준으로 전체 재계산을 권고한다. 유기물 신원 충돌 4건(Vernolate·Chlorozotocin·5700-39-0·Oxytetracycline)은 EPA 기준으로 수동 확정한다.
3. **STEP 5 원저 전문 검증.** 이제 유일한 실질 병목이다. 대상 우선순위: tier A 11종 → tier B 29종 중 반도체 관련 → 기존 16종. 물질이 아니라 **연구 단위로 1행씩** 기록한다. `S08c` 의 PMID와 `S07` 의 인용 출처가 시작점이고, ACGIH 7판·DFGOT 해당 권·CICAD 67 입수가 관문이다. **323행 추가 검토는 불필요하다**(`G13`).
4. **독성유형 틀 고정.** Type 3의 보상성 분리 규칙(R08)을 독성학적으로 검토해 확정한다. 표적장기·관찰지표·작용기전은 계속 별도 필드로 유지한다.
5. **그 다음에** 방법론 개발. 유형별 참조집합과 작용기 기반 스크리닝은 데이터 고정 이후다. 기존 최대 Tanimoto를 기준선으로 유지하고, 구조군 단일연결의 과도 확장(최대 71종) 민감도 분석을 별도로 수행한다.

## 7. 유지해야 할 제약

- 동물과 인체 혈액독성을 하나의 양성 라벨로 병합하지 않는다.
- 독성자료 부재를 음성 라벨로 기록하지 않는다.
- 공식 전 경로 유해성 분류와 인체 흡입 검증 근거의 역할을 분리한다.
- 표적장기 분류, 실제 관찰 독성지표, 독성 작용기전을 동일 개념으로 취급하지 않는다.
- 자동 추출 결과를 검토 완료로 처리하지 않는다. `review_state` 필드로 구분한다.
- 음성물질이 없으므로 AUROC·specificity·precision 등 일반 분류성능을 산출하거나 주장하지 않는다.
- Tanimoto 0.3 / 0.5 는 탐색적 구조 포괄성 기준이며 검증된 독성 판정 임계값이나 적용영역이 아니다.
- PubChem 구조감사와 EPA 기반 S03 을 혼용하지 않는다. 등록 체계가 다르다.
- 인용 건수를 독립 연구 수로 합산하지 않는다.
