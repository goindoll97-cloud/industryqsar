# 현행 연구 방향 v0.26-pilot2

v0.24 연구 목적 유지: NITE 공식 혈액계 유해성 분류와 분자구조를 활용해 산업화학물질 정밀평가 우선순위를 도출하고 인체 흡입/직업성 관련성을 별도 검토한다. 인체 흡입독성, 공식 전 경로 유해성, 실제 위해도를 혼동하지 않는다.

[이전 상세 프로토콜 v0.24](hematotoxicity_research_protocol_v24_ko.md) 및 [v0.26 실험 결과](../data/supplementary/hematotoxicity_v26/README.md) 참조.

- v0.25 전체 562 CAS 조회 완료, 구조 통과 332, 보류 230. A 349(기존 39 + 신규 310), B 8,110(미확인 후보 2,519; 공식 참조 123 분리).
- NITE 전 경로 분류는 공식 유해성 기준의 탐색 참조, 인체 16종은 잠정 별도 검증. 동물 흡입 요약 36종은 보완 후보이며 종간 전이/인체 양성으로 간주하지 않는다. 417행 중 82행 요약 검토, 335행 대기. 원저 검증 미완료.
- v0.26 4조건 실제 비교: 인체 16, 인체+기존 동물 18, 인체+NITE 336, 인체+동물 흡입 요약 49. 공통 구조군 제외에서 상위 회수 개선 없음. 전체 유사도 상승만으로 유용성 판정 금지.
- 다음 단계: 원저 및 산업 적용범위 검토, 335행 잔여 근거 정제. Hb 기능, 적혈구 손상, 혈구/골수 관련 기전 분리. 사전 정의한 작용기/기전 특화 방법과 기존 최대 Tanimoto를 동일 고정 배경과 구조군 기준으로 비교한다. 단순 임계값 조정이나 탐색 데이터에 맞춘 작용기 선택으로 성능을 낙관하지 않는다. 최대 71종 단일연결 군 형성의 영향은 별도 민감도 분석으로 보고(현 기준선 보존).
- 독립 인체 검증집합 확보 전 일반화 성능/독성확률/안전성 주장 금지. 자료 부족을 음성으로 해석하지 않는다. 출처 NITE/ATSDR/PubMed, 구조 EPA/PubChem 유지.
