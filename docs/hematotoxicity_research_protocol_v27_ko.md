# 현행 연구 방향 v0.27 — 보충자료 및 데이터 고정 단계

[v0.26 프로토콜](hematotoxicity_research_protocol_v26_ko.md)의 연구 목적 유지. NITE 공식 전경로 혈액계 유해성에 기반한 산업화학물질 우선평가 및 인체 흡입 관련성 별도 검토. 독성확률·안전성·실제 위해도·백혈병 인과 규명은 목표가 아니다.

[보충자료 정제 현황](../data/supplementary/hematotoxicity_v27/README.md) 참조. 공식 분류 562종 및 구조 감사 332통과/230보류 스냅샷 고정. A 349, B 8,110, 미확인 2,519 유지. 신규 최종 양성 라벨 0, 모델 실행 없음. 구조 통과 근거 417행 중 요약문 검토 94, 발췌문 선별 28, 자동 단서 295; 전체 검토 대기 323. 인체 16종 재점검 및 원저 관련 절 2건, 동물 원보고서 관련 절 1건 확인(독립 전체 원저 판정 아님). NITE 동물 흡입 요약 보완 39종 잠정; 기존 v0.26 실험에는 소급 반영하지 않는다.

## 최종 제출/실험 전 통과 조건
1. 독성 분류, species, route, endpoint를 개별 연구 단위로 검토한다. 요약문과 독립 원저, 측정 결과와 임상적 유해성을 구분한다. 자동 검색 단서는 라벨이 아니며 다중 노출/귀속 불명확/보상 반응을 보류한다. NITE 공식 유해성 자료로 사용하는 경우 공식 분류를 그대로 인용하고, 직접 흡입 및 기전을 주장하는 자료에는 해당 원저 확인이 필요하다.
2. 인체 잠정 검증물질 원저와 NITE 인용 중복 확인, 화학물질/구조군 누출 방지. 필요한 검증 집합과 전경로·흡입 참조 하위집합을 구분해 고정한다.
3. 신규 EPA export 원본, TRI 원래 목록/버전, 4개 한국 사용조사 원출처 및 공정 관련성을 보완한다. 기관 URL과 개별 물질 등재 확인은 구분한다. 산업 인벤토리는 실제 작업자 노출 증거가 아니다.
4. S1~S10을 최종 정제하고 공개 범위/데이터 사전을 확정한다. 현재 ZIP은 제출 전 초안이다. S11 최종 순위 및 새 모델 실험은 데이터 고정 후에 진행한다.

기존 구조 비교 기준선과 v0.26 내부 탐색 실험은 보존. 음성 없는 순위 실험으로 실제 분류성능, 독성확률, 검증된 적용영역을 주장하지 않는다.
